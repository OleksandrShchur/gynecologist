# Фото лікаря

У цій папці вже встановлено обидві надані фотографії:

- `photo-portrait.png` — 1080 × 1080 px; Оксана Перхулин за столом у лавандовому медичному одязі, рослина праворуч.
- `photo-standing.png` — 1092 × 1092 px; Оксана Перхулин стоїть зі схрещеними руками у світлому кабінеті.

Після заміни фото збережіть ці назви й запустіть `npm run images` або звичайну команду розробки чи збірки проєкту. Скрипт `scripts/optimize-images.mjs` створює WebP шириною до 480, 768 і 1120 пікселів у `src/assets/generated/`, зберігає пропорції, враховує орієнтацію фото та ніколи не збільшує оригінал. Поточні набори: 480 / 768 / 1080 px для портрета й 480 / 768 / 1092 px для фото стоячи. Для менших оригіналів створюються лише унікальні доступні розміри.

Модуль `src/content/images.generated.ts` містить імпорти готових зображень, `srcSet` та фактичні ширину й висоту. Компоненти використовують ці розміри, щоб зарезервувати місце до завантаження. Зміст модуля та файлів оновлюється лише за наявності змін.

Якщо оригінал надалі буде видалено, повторний запуск прибере відповідне поле `photos.portrait` або `photos.standing` із модуля, а фото не відображатиметься. Старі WebP не потрапляють до збірки через цей модуль. Підставних портретів немає.

Використовуйте лише фотографії, на публікацію яких отримано згоду.
